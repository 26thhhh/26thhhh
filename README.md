## KANSLOR Public Data Suite

A collection of Python applications made for displaying live city information

### 🚔 Crime
Collects and displays San Antonio Police Department public
calls-for-service data with location-based filtering.

**[View Crime →](https://github.com/26thhhh/crime)**

### 🔥 Fire
Collects and displays public fire and emergency-response information.

**[View Fire →](https://github.com/26thhhh/fire)**

### 🌦️ Weather
Terminal-based weather collection and monitoring application.

**[View Weather →](https://github.com/26thhhh/weather)**

### ✈️ Planes
Aircraft monitoring and terminal interface for aviation data.

**[View Planes →](https://github.com/26thhhh/planes)**

### 📡 Briefing
A consolidated terminal briefing application designed to surface useful
information from multiple data sources.

**[View Briefing →](https://github.com/26thhhh/briefing)**
